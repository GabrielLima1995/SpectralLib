Métodos espectrais em Julia

SpectralLib.jl agrupa os métodos espectrais do repositório em uma biblioteca Julia única, com transformadas, matrizes de diferenciação e pesos de quadratura prontos para usar.

Comece com Julia Ver exemplos
✔︎ 100% Julia ✔︎ Polinômios ortogonais ✔︎ Malhas prontas para plotar
Transformadas e quadraturas 
julia> using SpectralLib

julia> vals = [1, 0, -1, 0.5]
julia> spectral = ChebyshevTransform(vals, 1, 1)
julia> rec = ChebyshevTransform(spectral, 1, 2)

julia> z, w = ChebyQuadrature(-1, 1, 4, 1)
julia> D = DS_Cheby(3)

Primeiros passos

Instale a biblioteca e rode seu primeiro operador.

Instalação

pkg> add SpectralLib

A biblioteca expõe os módulos Chebyshev, Legendre, Fourier e Generic. Todos os símbolos principais são reexportados em using SpectralLib.

Primeiro passo

using SpectralLib

x = [-1.0, 0.0, 1.0]
B = Base_Legendre_n(3, x)
D = DS_Legendre(3)

z, w = ChebyQuadrature(-1, 1, 4, 2)
f̂ = B * cos.(x)

Bases espectrais

API consistente para polinômios ortogonais e séries trigonométricas.

Chebyshev

Transformada direta/inversa via FFT real, nós de Gauss/Lobatto/Radau e matrizes de diferenciação modais. 

spec = ChebyshevTransform([1,0,-1,0.5], 1, 1)
D = DS_Cheby(4)
z, w = ChebyQuadrature(-1, 1, 6, 2)

Legendre

Bases de Gauss, Lobatto e Radau, matrizes de integração e multiplicação e avaliação recursiva dos polinômios. 

BL, BI, xG, wG = Legendre_Gauss_Basis(3)
J = JS_Leg(3)

Fourier

Diferenciação espectral, interpolação trigonométrica e quadratura para funções periódicas. 

x, D = fourdif(9, 1)
vals = real_fft(sin.(x))
