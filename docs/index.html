Fast spectral methods in Julia

SpectralLib.jl gives you Chebyshev, Legendre, and Fourier bases with ready-to-use differentiation, integration, and transform utilities. Built for teaching, research, and production simulations.

Spectral expansion 
julia> using SpectralLib

# approximate f(x) = e^x on [-1, 1]
julia> basis = ChebyshevBasis(16)
ChebyshevBasis(16)

julia> coeffs = project(basis, x -> exp(x))
16-element Vector{Float64}: ...

julia> f̂ = reconstruct(basis, coeffs)
(x) -> 2.718...

julia> f̂(0.5)
1.64872

Getting started

Install the package and run your first transform.

Installation

pkg> add SpectralLib

SpectralLib.jl has zero external dependencies. After adding the package, load the base you want and start composing operators.

First approximation

using SpectralLib

basis = LegendreBasis(10)
coeffs = project(basis, x -> sinpi(x))

# Evaluate on the native Gauss nodes
values = evaluate(basis, coeffs)

# Recover a function handle
f̂ = reconstruct(basis, coeffs)
f̂(0.25)

Spectral bases

Consistent API across orthogonal polynomial and Fourier families.

Chebyshev

Use Chebyshev polynomials on [-1, 1] for rapid convergence of smooth functions, with cosine transforms and Clenshaw evaluation. 

basis = ChebyshevBasis(32)
D = differentiation_matrix(basis)

Legendre

Work with Gauss or Gauss–Lobatto nodes, integration weights, and recurrence coefficients for polynomial families.

basis = LegendreBasis(24)
weights = quadrature_weights(basis)

Fourier

Periodic expansions with FFT-friendly grids and spectral differentiation matrices.

basis = FourierBasis(64)
T = transform_matrix(basis)

Examples

Explore typical workflows with clear, copy-paste snippets.

Boundary value problem

Chebyshev

Solve u'' = sin(πx) with Dirichlet conditions using a spectral differentiation matrix. 

using SpectralLib, LinearAlgebra
N = 32
basis = ChebyshevBasis(N)
D2 = differentiation_matrix(basis, 2)

rhs = sinpi.(basis.nodes)
A = D2[2:end-1, 2:end-1]
b = rhs[2:end-1]

u = zeros(N)
u[2:end-1] = A \ b

Projection and reconstruction

Legendre

Project a smooth function and evaluate it on an arbitrary mesh.

basis = LegendreBasis(12)
coeffs = project(basis, x -> exp(-3x^2))
f̂ = reconstruct(basis, coeffs)

xs = range(-1, 1, length=200)
ys = f̂.(xs)

Fourier convolution

Fourier

Leverage circulant convolution with FFT-friendly bases.

basis = FourierBasis(64)
coeffs = project(basis, x -> sin(4πx) + 0.2cos(9πx))

# differentiate in spectral space
D = differentiation_matrix(basis)
coeffs′ = D * coeffs
